## 5 分钟自查（免费）

先跑这 5 条，很多问题不用花钱：

1. **解释器和 pip 是不是同一套**：`python -V` 和 `python -m pip -V` 的路径是否一致；不一致就统一用 `python -m pip`。
2. **Windows 执行策略**：`Get-ExecutionPolicy -List`。五项全是 `Undefined` 时，默认按 `Restricted` 处理，`.ps1` 会被拦。
3. **代理变量**：`$env:HTTPS_PROXY`、`$env:HTTP_PROXY`（Linux：`env | grep -i proxy`）。代理软件退出后变量可能还留着。
4. **只解析不安装**：`python -m pip install --dry-run "包==版本"`，重点看 `from versions:` 那一行有没有你要的版本。
5. **运行时 vs 驱动**：`docker version`、`nvidia-smi` 分别确认容器运行时和显卡驱动，不要把两层混成一个问题。
